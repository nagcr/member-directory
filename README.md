# NAGCR Member Directory
Code relating to generating the NAGCR Member Directory.

## directory_creator.html
This HTML file contains JavaScript that generates other HTML files.
It takes in a `csv` file of the member information, and produces an HTML file that allows you to search up members of the Guild.

### csv headers
`Reverse Fullname,Address1,Address2,City,State or Province,Zip Post Code,Country,Email Address,Home Phone,Work Phone,Fax,Cell Phone,Class Description,Area Name,Expiry Month,Expiry Year,Opt Out Online List,Memb Cat for Web Directory,Dear - - Salutation`
